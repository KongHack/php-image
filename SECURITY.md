# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature for this repository. If private reporting
is unavailable, contact a KongHack organization owner privately and include the
affected image tag or digest, reproduction details, and potential impact.

Security updates are applied to the mutable PHP compatibility tags. Consumers who
pin a release tag or digest are responsible for updating that pin when a fixed
image is published.
